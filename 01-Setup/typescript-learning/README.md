### 1. What is the difference between TypeScript and the JavaScript runtime?
Answer: TypeScript is a programming language that adds static typing to JavaScript. It is mainly used during developement.
On the other hand, JavaScript runtime is helps to execute JavaScript code such as Node.js.

### 4. What does tsc do?
Answer: tsc is the Typescript Compiler. It checks the Typescript code for type errors and compile Typescript code into Javascript code.

### 3. Why do we keep TypeScript as a dev dependency?
Answer: We keep TypeScript as a dev dependency because it is mainly needed during development time and build time. After compilation, the application runs as JavaScript.

### 4. What problem does tsconfig.json solve?
Answer: tsconfig.json defines how TypeScript should be checked and compiled. It allows us to configure things like the JavaScript target, module system, strictness, and output directory.

### 5. Why is a project-local TypeScript version useful?
Answer: A project-local TypeScript version ensures that the project uses a specific and consistent TypeScript version. It prevents version mismatches between different environments or developers.
